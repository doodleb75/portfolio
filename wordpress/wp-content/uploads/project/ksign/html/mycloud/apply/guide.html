서비스명 단독 서버 호스팅은 웹호스팅처럼 다수의 이용자가 하나의 서버를 공동으로 사용하는 것이 아니고, 해당 고객의 독립된 서버를 직접 관리 하고 운영 할 수 있는 서비스 입니다. 하나의 서버를 통째로 이용하므로, 초고속의 전송속도와 풍부한 하드 용량을 이용할 수 있습니다.

방문자 수가 많은 대용량 사이트의 경우, 웹호스팅을 이용하시면 서버 한대를 다른 웹호스팅 이용자들과 같이 쓰기 때문에 많은 방문자가 생기면 서버 부하가 늘어나며, 같은 서버를 이용하고 있는 다른 웹호스팅 이용자들 에게도 영향을 미칠 수 있습니다.
DB 용량이 방대하고 하루 평균 4기가 이상의 트래픽이 발생하는 사이트는 웹 호스팅 보다는 서버를 단독으로 사용하는 서버 호스팅을 이용하시는것이 좋습니다.
